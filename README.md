# E-Commerce Microservices DevOps Project

## Overview
A learning project demonstrating how to build and deploy an e-commerce application using DevOps tools.

## Technologies
- Git and GitHub
- Docker
- Kubernetes
- Jenkins CI/CD
- AWS
- Terraform
- Prometheus and Grafana

## Application Components
- Frontend: E-commerce shopping website
- Product Service: Product information
- Order Service: Order management
- Payment Service: Payment workflow simulation

## DevOps Implementation Plan
1. Store application code in GitHub.
2. Containerize the application using Docker.
3. Deploy application components to Kubernetes.
4. Automate build and deployment using Jenkins.
5. Provision AWS infrastructure using Terraform.
6. Add monitoring using Prometheus and Grafana.

## Project Status
Phase 1: Frontend and repository setup.

Further components will be implemented and tested incrementally.
